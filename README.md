# 智能图书整理与书架管理系统 (Book Organizer & Shelf) - GUI 桌面版

本项目专为将散乱、未整理的电子书库（如 `G:\123`）规范化整理为 Calibre 标准多层级书库目录（格式严格对齐 `D:\downloads\魏总的书库（已整理）(1)`），并提供了**一体化书架浏览、直接阅读、元数据编辑与管理**功能。

已封装为免安装的单文件 **`图书整理工具.exe`**，双击直接弹出现代化桌面窗口，无需命令提示符黑框。

---

## 一、新增核心功能：📚 我的书架 (Bookshelf)

在本次升级中，工具全面升级为**书架管理 + 智能整理**双标签页架构：

1. **直接打开观看阅读**：
   - 选中任意图书，双击表格行、按 `Enter` 键或点击 **“📖 立即打开观看”**，即可一键唤醒 Windows 系统默认阅读器（如 Calibre、Neat Reader、SumatraPDF、Edge 等）打开图书文件。
   - 若系统未关联 EPUB 阅读器，软件会自动提示并提供**内置轻量试读阅读器**，直接在窗口内解析并阅读图书章节与正文！
2. **高清封面与图书卡片**：
   - 右侧详情面板自动加载图书的 `cover.jpg` 高清封面，自适应比例缩放与卡片化呈现。
   - 实时呈现书名、作者、出版社、出版日期、ISBN、格式、文件大小与排版整洁的内容简介。
3. **元数据管理与快速编辑**：
   - 右键图书选择 **“✏️ 编辑图书元数据...”**，支持随时修改书名、作者、出版社、出版日期、ISBN 与简介，保存后同步写回 `metadata.json` 与 `.opf` 标准文件，并实时刷新列表。
4. **即时检索与格式过滤**：
   - 支持书名、作者、出版社、ISBN 的全局模糊检索。
   - 支持按文件格式快速筛选（全部格式、EPUB、PDF、MOBI、AZW3、TXT、其他）。
   - 点击表格表头（书名、作者、格式、大小、ISBN、出版社、日期）支持升序/降序即时排序。
5. **文件定位与删除管理**：
   - **“📁 打开目录”**：在 Windows 资源管理器中打开图书所在目录并自动高亮选中图书文件。
   - **“🗑️ 从书架删除”**：安全确认提示，彻底清理失效或废弃的书籍目录。
   - **外部联动检索**：右键可一键在【豆瓣读书】或【谷歌图书】中检索该书的官方条目。
6. **整理与书架自动联动**：
   - 在【图书整理】标签页完成整理入库后，后台会自动刷新书架数据，切换至【我的书架】即可立刻阅读新入库的图书！

## 二、双轨元数据引擎：内置多源 + Calibre 插件热插拔

系统采用创新的**双轨并行元数据架构**，既保证了开箱即用的高可用性，又完美继承了 Calibre 庞大的开源社区生态：

### 轨道 A（方案二）：内置原生五大元数据源（免配置、零外部依赖）
1. **豆瓣读书 (Douban)**：中文图书首选源，提取深度书名、作者、出版社、出版年、ISBN、评分与长篇简介，自动将封面小图转换为 `/l/public/` 高清大图。
2. **微信读书 (WeRead)**：中文正规出版物的高速直连源，响应极快且免验证码干扰，封面图自动升级为 `/t6_` 1080P 超高清封面。
3. **Open Library**：Internet Archive 旗下的公益开放图书库，全球外文书与公版书秒级识别，完全免 API Key、无反爬与频控限制。
4. **Google Books**：全球最大的图书数据索引库，支持复杂检索与全球出版物，支持填入个人专属 API Key。
5. **Bangumi (番组计划)**：针对日系动漫、轻小说、出版漫画等垂直图书，精准识别分卷、分册与出版 ISBN。

### 轨道 B（方案三）：Calibre 插件兼容垫片 (Calibre Plugin Shim & Loader)
系统底层内置了对 Calibre 运行环境（`calibre.ebooks.metadata.sources.base`、`Metadata`、`JSONConfig` 等）的仿真垫片，**无需在系统安装 Calibre，即可直接运行 Calibre 官方或社区的元数据插件**！

- **插件目录**：`calibre_plugins/`
- **使用方式**：直接将 Calibre 社区的插件（如 `douban.zip`、`goodreads.zip`、解压后的插件文件夹或 `.py` 脚本）拖入 `calibre_plugins/` 目录中。
- **自动装载**：程序启动时会自动解压、探测并加载继承自 `Source` 的插件，并优先参与 ISBN 与书名的匹配识别。

## 三、智能合集与 ISBN 识别规则

系统遵循严谨的双向验证与智能辨析决策：

1. **深入书内检索 ISBN**：
   - 自动扫描电子书全文（包括 OPF 元数据、版权页、CIP 数据、前言与正文等）。
   - 提取所有出现的合法出版 ISBN（支持 ISBN-10 与 ISBN-13，自动校验并归一化为 ISBN-13）。
2. **书内多 ISBN 双向联网验证（区分正规全集与拼凑合集）**：
   - **正规官方全集/套装（正常整理入库）**：以《草婴译著全集》为例，书内既包含各卷分册的出版 ISBN，也能在网络/书内匹配到该全集整套的官方出版 ISBN（如 `9787532169481`），且分卷均对应当前全集；系统经联网比对后**确认其为官方出版全集，正常整理入库**。
   - **散装拼凑合集（跳过不整理）**：以《巴菲特的投资理财课 全4册》、《顶级推理迷必读合集》为例，书内 4~5 个 ISBN 经联网验证分别属于互不相干的多本单行本（《证券分析的方法》、《巴菲特如是说》、《冷血》等），且合集名称本身在出版社和官方数据库中没有任何出版记录；系统**准确判定为无独立出版 ISBN 的民间拼凑本，自动跳过**。
3. **书名含合集字样但具备正式出版 ISBN（正常整理入库）**：
   - 如《白色巨塔（共3册）》、《第三帝国的兴亡：纳粹德国史（全四册）》，具备正式出版登记号，正常规范入库。
4. **无出版 ISBN 跳过**：
   - 网络小说、未正式出版的民间合订本等，在书内外均无法查证到合法出版 ISBN 的书籍，自动跳过不入库。

## 四、Google Books API Key 申请指引

> **提示**：Google Books API 在本工具中完全支持**免 Key 运行**（豆瓣与微信读书为国内中文主源，谷歌图书为辅）。如需更高专属配额防止网络 429 频控，可免费申请个人 Key：

1. 打开 [Google Cloud Books API 控制台](https://console.cloud.google.com/apis/library/books.googleapis.com)（软件界面中点击“申请Key...”按钮可一键直达）。
2. 登录任意 Google 账号，点击 **“启用 (Enable)”** Books API。
3. 进入 [凭据页面](https://console.cloud.google.com/apis/credentials)，点击顶部 **“+ 创建凭据” -> “API 密钥”**。
4. 复制生成的字符串（如 `AIzaSy...`），粘贴到软件界面的 **`Google Books Key`** 输入框中即可。
5. 软件会自动持久化保存该 Key，下次打开无需重复输入。

## 五、配置持久化说明

所有配置均已接入持久化存储 (`settings.json`)：
- **书库目录 & 源图书目录**：启动时自动加载上次使用的路径。
- **书架最后选中标签页**：记住关闭窗口时的活动标签页。
- **整理模式**（复制/移动）、**合集跳过开关**、**数量限制**、**请求延时**及 **Google API Key**，重启程序完全保留。
